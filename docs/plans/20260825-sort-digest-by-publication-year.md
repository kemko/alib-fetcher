# Сортировка дайджеста по году издания

## Overview

Перед формированием Telegram-сообщений сортировать все pending-книги по
`PublicationYear` по убыванию. Книги с одинаковым годом сохраняют порядок первого
обнаружения; нераспознанный год `0` оказывается в конце.

## Context

- Files involved: `internal/app/service.go`, `internal/app/service_test.go`,
  `README.md`, `AGENTS.md`
- Related patterns: `State.Pending` сохраняет долговременный порядок первого
  обнаружения; `app.Service` управляет порядком отправки и подтверждения; `digest`
  рендерит книги в полученном порядке
- Dependencies: новые зависимости не нужны
- Сортировка применяется только к конкретному дайджесту: порядок записей и
  `queue_order` в bbolt не меняются
- Будущие годы участвуют в обычном числовом сравнении и отправляются раньше текущих

## Development Approach

- **Testing approach**: Regular (сначала минимальная логика, затем регрессионный тест)
- Использовать стабильную сортировку стандартной библиотеки непосредственно перед
  `digest.RenderSendable`
- Не переносить политику сортировки в `store` или `digest`
- Полностью завершить каждую задачу и получить успешные тесты перед следующей
- Каждое изменение логики сопровождается новым или обновлённым тестом
