# Пауза между загрузками Alib, HTTP-коды в логах и нормализация года

## Overview

Вернуть конфигурируемую паузу с дробными секундами. Закрепить требование HTTP 200
после редиректов, всегда указывать код ответа в событиях Alib и распознавать
нестандартные записи года.

## Context

- internal/config/config.go: строгий TOML, проверка разрешённых ключей и длительностей.
- internal/alib/client.go: последовательные загрузки, отдельный backoff повторов, проверка HTTP 200 и
последующий разбор страниц.
- internal/alib/parser.go: parsePublicationYear и hasYearSuffix.
- internal/alib/book.go: тот же разбор года используется при чтении legacy-записей.
- cmd/alib-fetcher/main.go: создание клиентов; config.Config входит в ключ сравнения конфигураций при
перезагрузке.
- Ответы не 200 уже возвращают ErrUnexpectedStatus и повторяются. Используется стандартный
http.Client с обработкой редиректов.
- Новые зависимости не нужны.

## Development Approach

- Regular: реализация, затем регрессионные тесты в существующих файлах.
- Полностью завершать каждую задачу перед следующей; каждая задача включает новые
или обновлённые проверки.
- После каждой задачи запускать rtk make test; переходить дальше только при успехе.
- Использовать httptest и синхронизацию; проверки времени не должны требовать точного
совпадения длительностей.
- Сохранить последовательность источников, частичные результаты, отдельный backoff и
разбор только после завершения всех загрузок.
