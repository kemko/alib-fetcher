# Emoji для будущих книг и корректный межблочный отступ

## Overview

Добавить маркер `🛸` для книг с распознанным годом издания больше текущего локального года. Маркер работает независимо от `FRESH_BOOKS`; правила `🔥` и `✨` остаются прежними.

Сократить HTML-разделитель между смысловыми `<p>`-блоками книги с `<br/><br/>` до `<br/>`, чтобы Telegram показывал одну пустую строку. Внутренние переносы строк `<br/>`, разделитель объявлений `<hr/>`, заголовок и chunking-семантика сохраняются.

## Context

- Files involved:
  - `internal/digest/render.go`
  - `internal/digest/render_test.go`
  - `internal/app/service_test.go`
  - `cmd/alib-fetcher/main_test.go`
  - `README.md`
  - `AGENTS.md`
- Related patterns:
  - `publicationEmoji` классифицирует `PublicationYear` относительно `Options.LocalTime.Year()`;
  - `app.Service` уже переводит время цикла в настроенную `TIMEZONE`;
  - `FRESH_BOOKS` влияет только на `✨`;
  - парсер уже сохраняет любой распознанный четырёхзначный год, включая будущий;
  - `renderBook` собирает непустые `<p>`-блоки через единый `paragraphBreak`;
  - точные HTML-тесты фиксируют escaping, переносы, rune-based limits и границы chunks.
- Dependencies:
  - новые зависимости и настройки не нужны;
  - модель `alib.Book`, парсер, конфигурация и хранилище не меняются.
