# Путь конфигурации через переменную окружения

## Overview

Добавить `ALIB_FETCHER_CONFIG` через встроенный механизм urfave/cli.

- Приоритет: явно переданный `-config`/`--config`, затем `ALIB_FETCHER_CONFIG`, затем `./config.toml`.
- Поддержать все режимы: `-once`, `-service`, `-forget-latest`.
- Пустое значение сохраняет существующее поведение загрузчика: `./config.toml`.
- Относительные пути считаются от рабочего каталога.
- Ошибка чтения выбранного файла возвращается без поиска другого файла.

## Context

- `cmd/alib-fetcher/main.go`: объявление флага `config` и передача пути загрузчикам.
- `cmd/alib-fetcher/main_test.go`: тесты CLI и запуска.
- `internal/config/config.go`: общий загрузчик; уже обрабатывает пустой путь и преобразует относительный путь в абсолютный.
- `README.md` и `AGENTS.md`: описание выбора конфигурации.
- Использовать `Sources: cli.EnvVars("ALIB_FETCHER_CONFIG")`. Новые зависимости не нужны.

## Development Approach

- **Testing approach**: Regular — код, затем регрессионные тесты.
- Завершать каждую задачу и успешно выполнять тесты перед следующей.
- **CRITICAL: every task MUST include new/updated tests**.
- **CRITICAL: all tests must pass before starting next task**.
- Тесты с изменением окружения выполнять без `t.Parallel()`; изолировать окружение от настроек разработчика.
- Проверки запускать через Makefile.
