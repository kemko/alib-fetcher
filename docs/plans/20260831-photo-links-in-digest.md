# Ссылки на фотографии в дайджесте

## Overview

Заменить булевый признак фотографий упорядоченным списком ссылок. Дайджест будет
выводить блок `Смотрите: фото - фото` со всеми ссылками из объявления, а при их
отсутствии полностью пропускать поле.

## Context

- Files involved: `internal/alib/book.go`, `internal/alib/parser.go`, `internal/alib/book_test.go`, `internal/alib/parser_test.go`,
  `internal/digest/render.go`, `internal/digest/render_test.go`, `internal/store/store_test.go`, `README.md`
- Related patterns: DOM-разбор ссылок через `listingPart`, `isPhotoLink` и `resolveURL`; безопасная HTML-отрисовка
  через `renderLink`; автоматическая перезапись сохранённой книги текущей JSON-схемой при
  следующей мутации
- Dependencies: новые зависимости не нужны
- Старые записи с `has_photos` продолжат декодироваться: неизвестное поле будет
  проигнорировано, а недоступные URL восстановить невозможно

## Development Approach

- **Testing approach**: Regular
- Каждая задача завершается тестами и `make test` до перехода к следующей
- Сохранить порядок и повторы ссылок из объявления
- Относительные URL преобразовывать в абсолютные
- Все динамические URL экранировать существующим механизмом Telegram HTML
