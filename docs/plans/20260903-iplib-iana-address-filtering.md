# IANA-реестр iplib для фильтра адресов Slink

## Overview

Заменить собственные таблицы и проверки недоступных IP-диапазонов на `github.com/c-robinson/iplib/v2/iana`. Запрещать адрес, если `iana.GetReservationsForIP` возвращает хотя бы одну запись, независимо от полей `Global`, `Forwardable` и `Reserved`. Диапазоны вне реестра iplib/iana не блокировать.

## Context

- Files involved:
  - `go.mod`
  - `go.sum`
  - `internal/slink/client.go`
  - `internal/slink/client_test.go`
  - `README.md`
  - `AGENTS.md`
- Related patterns:
  - Все исходные и перенаправленные URL используют один `secureDialContext`, поэтому проверка остаётся общей для прямых запросов, HTTP redirects и META refresh.
  - Перед соединением проверяются все адреса из DNS-ответа; наличие одного запрещённого адреса отменяет соединение целиком.
  - `nil` и отсутствие DNS-адресов остаются ошибками независимо от политики диапазонов.
  - Локальные тесты должны проверять интеграцию и политику приложения, но не дублировать таблицу и тесты iplib.
- Dependencies:
  - Добавить `github.com/c-robinson/iplib/v2` версии `v2.0.5`.
  - iplib имеет MIT-лицензию, стабильный v2 API и одну транзитивную зависимость `lukechampine.com/uint128`.
  - IANA-реестр встроен в версию библиотеки и не загружается во время работы; его обновление выполняется обновлением зависимости.

## Development Approach

- **Testing approach**: Regular — сначала минимальная замена реализации, затем сокращение и уточнение тестов.
- Использовать напрямую `iana.GetReservationsForIP`; не создавать локальную обёртку или собственную классификацию диапазонов.
- Не учитывать флаги записей IANA: любая найденная запись означает запрет.
- Сохранить DNS rebinding protection: проверить весь DNS-ответ до первого вызова dial.
- Complete each task fully before moving to the next.
- **CRITICAL: every task MUST include new/updated tests.**
- **CRITICAL: all tests must pass before starting next task.**
