# Списки категорий и серий Alib вместо ALIB_URL

## Overview

Заменить произвольный `ALIB_URL` двумя CSV-настройками: `ALIB_CATEGORIES` и `ALIB_SERIES`. Категории
преобразуются в страницы `https://www.alib.ru/<category>.phtml?tnew=7`, серии — в
`https://alib.ru/findp.php4?seria=<encoded>&lday=7`. Обе настройки необязательны по отдельности и не имеют
значений по умолчанию, но запуск digest/service завершается ошибкой, если обе пусты.

## Context

- Files involved:
  - `internal/config/config.go`
  - `internal/config/config_test.go`
  - `internal/alib/client.go`
  - `internal/alib/client_test.go`
  - `cmd/alib-fetcher/main.go`
  - `cmd/alib-fetcher/main_test.go`
  - `docker-compose.yml`
  - `README.md`
  - `AGENTS.md`
- Related patterns:
  - `config.Load` валидирует пользовательские переменные до запуска процесса.
  - `alib.Client` уже выполняет страницы последовательно, сохраняет порядок, использует общий интервал,
    объединяет результаты и дедуплицирует книги по `BuyURL`.
  - `-forget-latest` читает только `STATE_PATH` и не должен требовать списки слежения.
  - Интеграционные тесты используют локальные `httptest.Server`; произвольный production-настройкой URL после
    удаления `ALIB_URL` не предоставляется.
- Dependencies:
  - Новые зависимости не нужны.
  - Для CSV и URL encoding используются стандартные `encoding/csv` и `net/url`.

## Development Approach

- **Testing approach**: Regular — сначала минимальное изменение кода, затем регрессионные тесты задачи.
- Полностью удалить пользовательский контракт `ALIB_URL` без совместимого fallback.
- Разбирать каждый список как одну CSV-запись, обрезать окружающие пробелы и отклонять пустые элементы или
  повреждённые кавычки.
- Категории принимать только как непустые слова из ASCII-латиницы без неоговорённой нормализации регистра.
- Серии принимать в Unicode; запятые внутри значения поддерживать через CSV-кавычки.
- Формировать query через `net/url`, чтобы спецсимволы серии не могли стать отдельными параметрами.
- Сохранять значения и повторы в исходном порядке: сначала категории, затем серии.
- Не менять двухфазную загрузку, частичный успех, логирование страниц, дедупликацию и digest.
- Complete each task fully before moving to the next.
- **CRITICAL: every task that changes code MUST include new/updated tests**
- **CRITICAL: all tests must pass before starting next task**
