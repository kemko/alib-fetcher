# Первое звуковое уведомление, книги без года и сокращение описаний

## Overview

Изменить дайджест так, чтобы звук был только у первого Telegram-сообщения; книги без
распознанного года выводились первыми и отмечались `🛸`; слишком длинный `Content`
сокращался с добавлением `…` вместо отказа от отправки книги.

## Context

- Files involved: `internal/app/service.go`, `internal/app/service_test.go`,
  `internal/digest/render.go`, `internal/digest/render_test.go`, `README.md`, `AGENTS.md`
- Related patterns:
  - `app.Service.Run` выбирает порядок книг и флаги `silent`/`attachRefresh`
  - `digest.Render` и `digest.RenderSendable` используют общий рендер и считают Unicode-руны готового HTML
  - `Chunk.Books` содержит исходные книги для подтверждения доставки
- Dependencies: новые зависимости и файлы не нужны
- `PublicationYear == 0` означает нераспознанный год
- Сокращается только `Book.Content`; заголовок, библиография, реквизиты продавца, фото и
  ссылка покупки сохраняются полностью
- Если обязательные части книги не помещаются даже с описанием `…`, сохраняется
  `ErrMessageTooLong`, и книга остаётся pending
- Цель сокращения — максимальная длина не более `MESSAGE_LIMIT - 1`. Из-за HTML-экранирования
  результат может быть на несколько знаков короче
- Старый refresh-button остаётся только у последнего чанка

## Development Approach

- **Testing approach**: TDD
- Полностью завершать каждую задачу перед следующей
- Сначала обновлять регрессионные тесты, затем вносить минимальное изменение
- После каждой задачи запускать канонический `make test`
- **CRITICAL: every task that changes code MUST include new/updated tests**
- **CRITICAL: all tests must pass before starting next task**
